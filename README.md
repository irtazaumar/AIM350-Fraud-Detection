# AIM 350 Fraud Detection Project

This project uses the PaySim synthetic financial transaction dataset to build and evaluate machine learning models for fraud detection.

## Project Goal
The goal is to compare machine-learning models for identifying fraudulent transactions and develop a live fraudbrisk scoring demonstration.

## Dataset
PaySim synthetic financial transaction dataset.

## Planned Models
- Logistic Regression
- Random Forest

## Planned Evaluation Metrics
- Precision
- Recall
- F1-score
- ROC-AUC
